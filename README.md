## 2. Установка и активация

### 2.1. Установка

1. Скопируйте папку `gaz-institute/` в `/wp-content/themes/`.
2. В админке: **Внешний вид → Темы** → активируйте **«ГИПК «ГАЗ-ИНСТИТУТ»»**.

### 2.2. Что создаётся автоматически при активации

- Меню **«Главное меню»** со всеми пунктами
- Страницы: **«Образование»**, **«Вакансии»**, **«О нас»**, **«Контакты»**
- 8 демо-вакансий (в CPT `vacancy`)

### 2.3. Настройка логотипа

**Внешний вид → Настроить → Свойства сайта → Логотип**.

Если логотип не задан, тема использует:

```
https://gazinstitut.by/wp-json/webdav-storage/v1/file/2021/11/cropped-Logo_0-1.png
```

## 4. Меню

### 4.1. Расположение

**Внешний вид → Меню → Главное меню**

Структура (создаётся автоматически):

```
Новости
О нас
Образование          ← переименовано из «Образовательная деятельность»
Филиалы              ← переименовано из «Филиалы института»
Наука
Вакансии
Лаборатория
Газета
Контакты
```

### 4.2. Переименование пунктов

Пункты «Образовательная деятельность» → «Образование» и «Филиалы института» → «Филиалы» переименовываются автоматически при первом заходе в админку после активации.

### 4.3. Как работает дропдаун

- Клик по родительскому пункту с `#` открывает подменю.
- На десктопе — hover + клик.
- На мобильных — полноэкранное выезжающее меню справа.
- Иконки в мобильном меню подбираются автоматически по названию (Новости → газета, Образование → книга и т.д.).

## 6. Вакансии

### 6.1. Где управлять

**Админка → Вакансии** (иконка портфеля слева).

### 6.2. Как добавить

**Вакансии → Добавить вакансию**:

| Поле | Обязательное | Описание |
|---|---|---|
| **Заголовок** | ✅ | Название должности |
| **Требования** | — | Высшее образование, стаж... |
| **Заработная плата** | — | `1 976 руб.` |
| **Ставка** | — | `1,0 ставки` / `0,5 ставки` |
| **Количество рабочих мест** | — | Число |
| **Режим работы** | — | `5-дневная рабочая неделя` |
| **Адрес** | — | `г. Минск, пер. Твёрдый 1-й, 8` |
| **Дополнительная информация** | — | Любой текст |
| **Иконка** | — | Выбор из 16 (портфель, преподаватель, инженер…) |
| **Кандидат подобран** | — | Чекбокс → бейдж «кандидат подобран» |
| **На перспективу** | — | Чекбокс → бейдж «на перспективу» |
| **Дата** | — | До какой даты флаг актуален |

### 6.3. Флаг «На перспективу» с автоснятием

- Если указана **дата** и она **раньше сегодняшней** — флаг снимается **сразу при сохранении**.
- Плюс раз в час на хуке `init` проверяются все вакансии, и у просроченных флаг снимается автоматически.
- Если дата не указана — флаг действует бессрочно.

### 6.4. Где на сайте

**`/vakansii/`** — страница с шаблоном «Газ — Вакансии». Прямых ссылок на отдельные вакансии нет (CPT `public => false`).

### 6.5. Редактирование / удаление

Стандартные действия WordPress в списке **Вакансии**:
- **Редактировать** — меняем любые поля
- **Удалить** → в корзину
- **Добавить новую**

## 7. Слайды главной страницы

### 7.1. Где управлять

**Админка → Слайды главной**.

### 7.2. Как добавить

**Слайды главной → Добавить слайд**:

| Поле | Описание |
|---|---|
| **Заголовок** | Внутреннее имя (для админки) |
| **Изображение записи** | Фон слайда (обязательно) |
| **Надзаголовок (overline)** | Мелкий текст сверху |
| **Заголовок** | Крупный заголовок |
| **Описание** | Полный текст |
| **Текст кнопки** | `Программы обучения` |
| **Ссылка кнопки** | `https://...` |
| **Брендовый слайд** | Чекбокс: показать логотип + теги |
| **Теги** | `fas fa-graduation-cap\|Образование; fas fa-flask\|Наука` (формат: иконка\|текст; иконка\|текст) |
| **Порядок** | В блоке «Атрибуты» → поле «Порядок» (меньше = раньше) |

### 7.3. Как отключить слайд

Удалить или снять с публикации (поставить «Черновик»).

### 7.4. Fallback

Если в CPT нет ни одного слайда — используются два дефолтных (из `helpers.php`). Поэтому после добавления хотя бы одного слайда дефолтные перестают показываться.

## 10. Новости

### 10.1. Где добавлять

**Записи → Добавить запись**.

### 10.2. Где показываются

- **Главная** — 6 последних новостей в сетке 3×2 (после бегущей строки, до баннеров).

- Если нет — берётся **первая картинка из текста** (поиск через регулярное выражение).

### 10.4. Количество записей на странице

- Категория `news`: 6 записей (задаётся через `pre_get_posts`).
- Остальные страницы: глобальная настройка **Настройки → Чтение**.

## 11. Быстрые ссылки

### 11.1. Главная страница

Сетка 3×2 (6 карточек) в `.gaz-shell`. Карточки настраиваются в `inc/helpers.php` → `gaz_get_quick_links()` (или через фильтр `gaz_quick_links`).

Каждая карточка:

```php
[
    'url'          => home_url('/prombez/'),
    'icon'         => 'fas fa-shield-alt',
    'title'        => 'Промбезопасность',           // короткое
    'title_full'   => 'Проверка знаний...',         // полное (tooltip)
    'subtitle'     => 'Проверка знаний',            // опционально
    'sub'          => '',
    'long'         => true,                         // стиль карточки
]
```

### 11.2. Внутренние страницы

Компактные пилюли в `.gaz-page-head` (под хлебными крошками), выводятся через `template-parts/quick-bar.php`. Все пилюли **фиксированной высоты 48px**, длинные названия разбиваются на две строки (`title` + `subtitle`).

### 11.3. Как изменить набор

Через фильтр в `functions.php`:

```php
add_filter('gaz_quick_links', function ($links) {
    // Добавить свою
    $links[] = [
        'url' => home_url('/new-link/'),
        'icon' => 'fas fa-star',
        'title' => 'Новая ссылка',
    ];
    return $links;
});
```

## 12. Аккордеоны

Тема поддерживает два типа аккордеонов:

### 12.1. Шорткод `[accordion_from_meta]`

```
[accordion_from_meta id="745"]
```

Где `745` — ID записи, в метаполе `accordions_options` которой лежит JSON с полями `header`/`body`. Используется для переноса аккордеонов из плагина Accordions.

### 12.2. Плагин PickPlugins Accordions

Работает «из коробки», тема применяет к нему свои стили.

### 12.3. Таблицы внутри аккордеонов

Автоматически оборачиваются в `.gaz-table-wrap` с горизонтальной прокруткой. На мобильных таблицы можно скроллить пальцем.

## 13. Версия для слабовидящих (BVI)

Кнопка в шапке `<a class="bvi-open">`. Работает через библиотеку `bvi@2.0.0` с CDN:

```
https://cdn.jsdelivr.net/npm/bvi@2.0.0/dist/css/bvi.min.css
https://cdn.jsdelivr.net/npm/bvi@2.0.0/dist/js/bvi.min.js
```

### 13.1. Локальная копия (если CDN недоступен)

Скачайте архив с GitHub: `https://github.com/veks/button-visually-impaired-javascript/archive/master.zip`

Распакуйте и положите:

```
/wp-content/themes/gaz-institute/assets/vendor/bvi/bvi.min.js
/wp-content/themes/gaz-institute/assets/vendor/bvi/bvi.min.css
```

В `functions.php` замените CDN-ссылки:

```php
wp_enqueue_style('bvi-style', GAZ_THEME_URI . '/assets/vendor/bvi/bvi.min.css', [], '2.0.0');
wp_enqueue_script('bvi-script', GAZ_THEME_URI . '/assets/vendor/bvi/bvi.min.js', [], '2.0.0', true);
```

## 15. Миграция dev → production

### 15.1. Подготовка на `dev.gazinstitut.by`

1. **Убедиться, что всё работает** на dev (тест всех страниц).
2. **Обновить постоянные ссылки**: **Настройки → Постоянные ссылки → Сохранить**.
3. **Сделать бэкап** через плагин (UpdraftPlus / Duplicator / All-in-One WP Migration) или вручную:
   - База данных: `mysqldump -u USER -p DBNAME > gaz_db.sql`
   - Файлы: `tar -czf gaz_files.tar.gz /path/to/wp-content/`
4. **Экспортировать настройки** плагинов (если есть).
5. **Сохранить список активных плагинов**: **Плагины → Установленные** — сделать скриншот.

### 15.2. Подготовка на `gazinstitut.by`

**Важно:** все работы — **в нерабочее время** или через `.maintenance`-режим.

#### Вариант А. Если на production уже стоит WordPress (чистый)

1. **Установить тему**: скопировать `gaz-institute/` в `/wp-content/themes/`.
2. **Активировать тему**.
3. **Установить плагины** из списка dev (те же версии):
   - GTranslate
   - PickPlugins Accordions
   - Draw Attention (для страницы «Филиалы»)
   - BVI (если локально)
   - Кеш-плагин (WP Super Cache / LiteSpeed / W3TC)
   - Оптимизация картинок (если используется)
4. **Перенести контент**:
   - Записи, страницы, меню, CPT, слайды, баннеры, гос-ссылки — через **Инструменты → Экспорт** (XML) с dev и **Импорт** на prod.
   - Медиафайлы — отдельно (FTP или плагин).
5. **Настроить Customizer**: контакты, соцсети, логотип.
6. **Убедиться, что настройка «Настройки → Чтение → На главной отображается» → «Статическая страница»** указывает на правильную страницу.

#### Вариант Б. Полный перенос (с сохранением всего)

1. **Очистить кеш** на dev.
2. **Выключить все кеш-плагины** на dev.
3. **Экспортировать БД**:
   ```bash
   mysqldump -u devuser -p devdb --single-transaction --quick > dev_export.sql
   ```
4. **Заменить домен в SQL** (после импорта на prod):
   ```bash
   wp search-replace 'dev.gazinstitut.by' 'gazinstitut.by' --all-tables --precise
   ```
   Или через `sed`:
   ```bash
   sed -i 's/dev\.gazinstitut\.by/gazinstitut.by/g' dev_export.sql
   ```
5. **Экспортировать файлы**:
   ```bash
   tar -czf dev_files.tar.gz /path/to/wp-content/
   ```
6. **Импортировать SQL** на prod:
   ```bash
   mysql -u produser -p proddb < dev_export.sql
   ```
7. **Распаковать файлы** на prod.
8. **Обновить wp-config.php** на prod:
   ```php
   define('DB_NAME', 'proddb');
   define('DB_USER', 'produser');
   define('DB_PASSWORD', 'prodpass');
   define('DB_HOST', 'localhost');
   define('WP_HOME', 'https://gazinstitut.by');
   define('WP_SITEURL', 'https://gazinstitut.by');
   ```
9. **Удалить старые плагины кеша** и поставить заново.
10. **Пересохранить постоянные ссылки**: **Настройки → Постоянные ссылки → Сохранить**.
11. **Перегенерировать миниатюры**: плагин **Regenerate Thumbnails** или:
    ```bash
    wp media regenerate --yes
    ```

### 15.3. Настройка после переноса

#### Обязательно

1. **SSL-сертификат** — установить и включить.
2. **Редирект http → https** — через `.htaccess` или настройки хостинга.
3. **Проверить `.htaccess`**:
   ```apache

## 17. Диагностика проблем

### 17.1. Стили не применяются на внутренних страницах

**Причина:** `style.css` не грузится.

**Диагностика:**

1. **Ctrl+U** на странице → поиск `style.css` в `<head>`.
2. **F12 → Network** → `style.css`:
   - `200` — грузится, проблема в CSS.
   - `404` — неверный путь.
   - Нет в списке — не подключается.

**Решение:**

В `header.php` должно быть **прямое подключение**:

```php
<link rel="stylesheet" href="<?php echo esc_url(GAZ_THEME_URI . '/style.css?v=' . GAZ_THEME_VERSION); ?>">
```

И в `functions.php` **не должно быть** `wp_enqueue_style('gaz-main', ...)` (удалено, чтобы избежать конфликта с плагинами кеша).

### 17.2. Стили не обновляются после правки

**Причина:** кеш браузера или плагина.

**Решение:**

1. В `functions.php` поднять версию:
   ```php
   define('GAZ_THEME_VERSION', '1.0.0'); // → '1.0.10'
   ```
2. Очистить кеш плагина (WP Rocket / LiteSpeed / W3TC).
3. Очистить Cloudflare (Purge Everything).
4. **Ctrl+F5** на странице.

### 17.3. Слайды не отображаются

- Проверить, что CPT **«Слайды главной»** содержит хотя бы одну **опубликованную** запись.
- Проверить, что у записи задано **Изображение записи** (иначе слайд пропускается).
- Если пусто — работают 2 дефолтных слайда из `helpers.php`.

### 17.4. Вакансии показывают старую вёрстку

**Причина:** у страницы `/vakansii/` не выбран шаблон.

**Решение:** **Страницы → Вакансии → Атрибуты страницы → Шаблон: «Газ — Вакансии»** → Обновить.

### 17.5. BVI не открывается

1. **F12 → Console** — есть ошибка `isvek is not defined`?
2. **F12 → Network** — `bvi.min.js` загружается? Статус `200`?
3. Если `404` или `blocked` — CDN недоступен. Скачать библиотеку локально (см. раздел 13.1).

### 17.6. Аккордеоны «дёргаются» при открытии

**Причина:** jQuery UI переопределяет ширину панели.

**Решение:** в `main.js` и `functions.php` есть принудительная установка `width:100%!important` на панели. Если проблема осталась — проверить, что `main.js` загружается (`F12 → Network`).

### 17.7. Таблицы в аккордеонах не скроллятся на мобильных

- В CSS должно быть: `.gaz-table-wrap{overflow-x:auto;-webkit-overflow-scrolling:touch}`.
- В `main.js` — функция `wrapTablesIn()`, оборачивающая таблицы.
- Проверить в **F12 → Elements**, что таблица внутри `<div class="gaz-table-wrap">`.

### 17.8. Ошибка «Слишком много перенаправлений» (ERR_TOO_MANY_REDIRECTS)

**Причина:** неверные `WP_HOME`/`WP_SITEURL` или SSL-редирект.

**Решение:**

1. В `wp-config.php`:
   ```php
   define('WP_HOME', 'https://gazinstitut.by');
   define('WP_SITEURL', 'https://gazinstitut.by');
   ```
2. Проверить `.htaccess` (без лишних `RewriteRule`).
3. Проверить настройки SSL в хостинге.

### 17.9. Белый экран после активации темы

**Причина:** фатальная ошибка PHP.

**Решение:**

1. В `wp-config.php`:
   ```php
   define('WP_DEBUG', true);
   define('WP_DEBUG_LOG', true);
   define('WP_DEBUG_DISPLAY', false);
   ```
2. Открыть `wp-content/debug.log` — там будет ошибка.
3. Если не открывается админка — переименовать папку темы через FTP, войти в админку, переключиться на дефолтную тему, разобраться.

### 17.10. 404 на всех страницах кроме главной

**Причина:** не работают `.htaccess` / mod_rewrite.

**Решение:**

1. **Настройки → Постоянные ссылки → Сохранить** (перегенерирует `.htaccess`).
2. Проверить, что в `.htaccess` есть правила из раздела 15.3.
3. На nginx — проверить `try_files $uri $uri/ /index.php?$args;`.
